## 6. Suggested Build Notes

- **Contact form destination:** route to hello@prominence.agency (or a CRM/inbox once set up).
- **Primary CTA everywhere:** "Book a Strategy Call" — keep this consistent across Home, Services, and Pricing so analytics can track one clear conversion goal.
- **Placeholder handling:** Since testimonials/case studies aren't ready yet, use a "Currently onboarding our first clients" note instead of leaving the section empty — keeps credibility while it's being built out.
- **Mobile-first:** Given the audience (busy executives checking on mobile), prioritize a clean single-column layout and fast load time over heavy visuals.
